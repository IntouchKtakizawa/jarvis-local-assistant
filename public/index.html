Internet access & privacy

With Internet on, Jarvis searches public factual questions using DuckDuckGo, reads up to three public pages, and includes source links. Paste a public HTTPS URL to ask about a specific page. Only your latest lookup query is sent to the search provider; your conversation is not. Page reading does not use browser cookies or your signed-in accounts.

Some websites block reading or require JavaScript; those sources are marked Search result. Lookup failures appear above your message box. Internet off disables automatic web and topic lookups. Direct image searches still use Wikimedia Commons.

Memory & saved conversations

Conversations now save on this Mac and can be resumed in Workspace → Conversations. The model uses up to 39 exchanges in the selected conversation. Older conversations remain separate; they are not all sent to the model.

Personal memory saves facts you explicitly ask Jarvis to remember and can carry them into new chats. View or delete them in Workspace → Memory, or switch the Memory add-on off. Local calendar plans remain separate in browser storage.

Live voice sends your speech after a short pause, reads the reply aloud, then listens again. You can stop at any time. It uses local Whisper and local speech synthesis.
