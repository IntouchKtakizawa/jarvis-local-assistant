03 / BRING IT HOME

From preview
to your desk.

Start with text chat. Add local speech when you’re ready. Requires Node.js 22.9 or later; a current browser; and internet for ChatGPT sign-in and replies.

Read the full setup guide ↗Download source ZIP ↓
LOCAL SETUP
git clone https://github.com/IntouchKtakizawa/jarvis-local-assistant.git
cd jarvis-local-assistant
npm ci
npm start
  1. Open http://127.0.0.1:3210 on your machine.
  2. Click Continue with ChatGPT and sign into your own account.
  3. Choose a model and start a conversation.
